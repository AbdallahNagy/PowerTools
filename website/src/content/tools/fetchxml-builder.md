## Build FetchXML without writing XML

FetchXML Builder is a visual query builder for Microsoft Dataverse and Dynamics 365. Pick a table, choose columns, and add conditions from the table's real metadata. PowerTools writes the FetchXML for you.

Filters offer the operators that fit each column type, so you do not have to remember operator names. Add related tables to filter across lookups. The builder generates the `link-entity` joins.

## See it and run it

The generated FetchXML stays visible as you build, with a button to copy it into a plug-in, a Power Automate flow, a view, or a report. Run the query to see the results in a grid, add or remove columns right from the grid header, and open any row as a record in Dynamics 365.

## When to use it

- Writing FetchXML for plug-ins, Web API calls, or Power Automate.
- Checking which records a filter really matches before you use it in code.
- Learning FetchXML by watching the XML change as you click.

Have a query already? Paste it into [FetchXML Tester](/tools/fetchxml-tester/) to run it exactly as written.
