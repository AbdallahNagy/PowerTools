## Translate your app in one grid

Translator shows the labels of a Dataverse or Dynamics 365 environment with one column for each installed language. Instead of switching your user language and editing labels one at a time, you edit them side by side and see the gaps at a glance.

Pick a table from the list, or pick **Global choices**. For a table, tabs cover the table itself, its columns, local choices, Yes/No labels, relationship menu labels, views, and charts.

## Edit, review, apply

Type straight into the grid. Edits are kept as you move between tabs and tables, and each table shows how many unsaved edits it holds. When you are ready, **Apply changes** writes every edit to Dataverse in one go. You can also discard all edits.

Choose which languages to show, and whether to show names, descriptions, or both. A filter matches component names and any label in any visible language, which makes it easy to find a label that was never translated.

## When to use it

- Adding a new language to an existing app.
- Fixing inconsistent wording across tables and views.
- Reviewing translations before a release.
