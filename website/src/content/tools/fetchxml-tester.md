## Run FetchXML exactly as written

FetchXML Tester is a fast way to run a FetchXML query against Dataverse or Dynamics 365. Paste the query, format it, and run it. The results appear in a grid with the row count and whether more records exist beyond the first page.

Nothing rewrites your query. What you paste is what runs, which makes it ideal for checking FetchXML copied from code, a view, a report, or a flow.

## Raw or formatted values

Turn on **Show formatted values** to see option labels, lookup names, and formatted dates and currency instead of raw values.

## A library of your queries

Save a query with a description and it goes into a local library on your machine. Search the library by table, description, query text, or environment, and load a saved query with a double click. You can see the queries for the current environment or for all of them.

## When to use it

- Debugging FetchXML from a plug-in or a Power Automate flow.
- Keeping a personal set of diagnostic queries for each environment.
- Running a query you built in [FetchXML Builder](/tools/fetchxml-builder/) with hand edits.
